# Projeto de TCC para a formação do curso FORD ENTER e projeto de aprendizagem (P.A) para o curso de Mecatrônica!

O site célia foi feito para a informação e cuidado de pacientes com alzheimer e para a venda do produto "Célia" uma pulseira inteligente que verifica sinais fisiologicos do paciente e os transforma em dados onde profissionais de saúde e familiares podem realizar o monitoramento preciso de sinais de estresse no paciente, dando assim uma melhora na qualidade de vida tanto do paciente quanto dos familiares e médicos.
